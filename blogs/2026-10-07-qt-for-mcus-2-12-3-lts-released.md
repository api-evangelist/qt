Qt for MCUs 2.12.3 LTS has been released and is available for download. This patch release provides several bug fixes and other improvements while maintaining source compatibility with Qt for MCUs 2.12 (see Qt for MCUs 2.12 LTS released ). This patch release is stability and user workflow focused and does not add any new functionality.
